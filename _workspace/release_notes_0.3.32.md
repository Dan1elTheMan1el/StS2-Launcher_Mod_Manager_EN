## 수정 내용

### issue #55 — 캐릭터/모드 선택 화면 멈춤 (softlock)
- 일부 모드(HextechRunes 등)가 초기화 중 게임의 언락 상태를 게임 모델 준비 전에 건드려 내부 타입이 영구 오염되고, 이후 모든 세이브·언락 처리가 실패해 모드 선택 버튼이 반응하지 않던 문제를 근본 해소했습니다.
- 0.3.31에 넣었던 init-setter 수정이 실제로는 로딩 순서 때문에 비활성 상태였던 것도 함께 바로잡았습니다(이제 정상 동작).

### 게임 v0.108.0 세이브 경로 호환
- 게임이 세이브 경로 함수 시그니처를 변경하면서 Save Manager가 "Method not found"로 멈추던 문제를, 구/신 게임 버전(≤v0.107.1 / v0.108.0) 모두에서 동작하는 런타임 호환 계층으로 해결했습니다.

### Save Manager
- 로컬과 클라우드가 이미 일치할 때 상태만 확인하고 닫아도 세션 클라우드 동기화가 꺼지던 문제를 수정했습니다.

## 알려진 사항
- HextechRunes의 전투 훅은 게임 v0.108.0의 내부 변경으로 모드 자체가 비호환입니다(런처와 무관, 모드 측 업데이트 필요).

## 적용
인앱 업데이트 또는 릴리즈의 APK를 덮어 설치. 세이브·로그인 보존.
